--- speaker notes ---
Start concrete. The input is a grid of grey levels; the output is one of ten labels. Everything that follows is about building a function from the 784 numbers to the label.

=== SLIDE 3 ===
Start from logistic regression 
 [FIGURE: live canvas]
 another digit Click a template to enlarge it. 
 $\cp{p_k} = \Pr(y = k \mid \cx{\bx}) = \dfrac{\exp(\cw{\bw_k}^{\!\top}\cx{\bx} + \cw{b_k})}{\sum_{j} \exp(\cw{\bw_j}^{\!\top}\cx{\bx} + \cw{b_j})}$ 
 Each class $k$ has its own weight vector $\cw{\bw_k}$ with 784 entries, a template. 
 The softmax turns the ten scores $\cw{\bw_k}^{\!\top}\cx{\bx} + \cw{b_k}$ into probabilities. 
 Drawn as an image: red pixels raise the score for $k$, blue pixels lower it. 
 Fit on 60,000 images: 90% test accuracy. Each class gets one straight boundary; the remaining errors need a curved one.
--- speaker notes ---
This is multinomial logistic regression, the model the class already knows. The weights are a template per class. The score for class k is the match between the image and template k. Softmax turns the ten scores into probabilities. Ten percent of test digits are wrong, and no choice of the ten templates fixes that: the score for each class is linear in the pixels, so each boundary is flat.

=== SLIDE 4 ===
A hidden layer learns features 
 Two inputs here instead of 784, so the boundary can be drawn. [FIGURE: live canvas]
 data [menu] 
 hidden units [slider] 4 
 $\varphi$ [menu] 
 learning rate $\eta$ [slider] 
 train reset 
 $\ch{\bh} = \varphi(\cw{\bW_1}\cx{\bx} + \cw{\bb_1})$ 
 $\cp{\bp} = \mathrm{softmax}(\cw{\bW_2}\ch{\bh} + \cw{\bb_2})$ 
 Each hidden unit is a weighted sum of the inputs, then a nonlinear $\varphi$; here ReLU, $\varphi(z) = \max(0, z)$. 
 Its weighted sum is zero along one straight line (small panels). 
 The output layer is multinomial logistic regression on the hidden units, so the boundary curves. 
 With a linear $\varphi$, $\cw{\bW_2}(\cw{\bW_1}\cx{\bx}) = (\cw{\bW_2}\cw{\bW_1})\cx{\bx}$: one straight boundary again.
--- speaker notes ---
This is the whole idea of the lecture. Two inputs instead of 784 so the boundary can be drawn; the data are the XOR pattern (classes by quadrant), rings, or a spiral. First set one hidden unit: one straight line, and on XOR accuracy stalls near fifty percent. Then raise the hidden units: each learned feature is a half-plane, and multinomial logistic regression on those features gives a boundary that bends. Switch to the linear activation: two linear maps compose to one linear map, so the model is again logistic regression on the raw inputs and the boundary stays straight. The learning rate eta is the step size of training, defined two slides on.

=== SLIDE 5 ===
The forward pass on a digit you draw 
 [FIGURE: live canvas]
 clear test digit Draw in the left box with the mouse. 
 $\cx{\bx} \;\xrightarrow{\;\cw{\bW_1},\;\varphi\;}\; \ch{\bh} \;\xrightarrow{\;\cw{\bW_2},\;\mathrm{softmax}\;}\; \cp{\bp}$ 
 The forward pass computes $\cp{\bp}$ from $\cx{\bx}$, layer by layer. 
 This network was trained beforehand on all 60,000 images: 64 ReLU units, 97% test accuracy. 
 Draw a digit and watch the 784 inputs become 64 features, then 10 probabilities.
--- speaker notes ---
The 8 by 8 grid is the hidden vector h; dark cells are active units, those whose ReLU output is positive. The bars are p. Draw a 7 with a crossbar, or a thin 1, and watch the probabilities move. A badly centred digit fails: the network has no translation invariance.

=== SLIDE 6 ===
Learning: gradient descent on the negative log-likelihood 
 [FIGURE: live canvas]
 surface [menu] 
 $\eta$ [slider] 
 step run reset 
 Click the plot to choose a start. 
 $L(\btheta) = -\frac{1}{n}\sum_{i=1}^{n} \log \cp{p_{y_i}}(\cx{\bx_i};\btheta)$ 
 The loss is the average negative log-likelihood, as in logistic regression. $\btheta$ holds every weight and bias. 
 There is no closed form, and Newton's method would need a 50,890 × 50,890 Hessian. 
 $\btheta \;\leftarrow\; \btheta - \eta\,\cl{\nabla_{\btheta} L(\btheta)}$ 
 So we step downhill by $\eta$ times the gradient. Too small is slow; too large jumps across the valley.
--- speaker notes ---
The loss is minus the log of the probability the network assigns the true class, averaged over the data: the same objective as logistic regression, with the hidden layer's weights added to theta. For logistic regression that objective is convex and Newton's method, IRLS, solves it in a few steps. With a hidden layer it is not convex and theta has 50,890 entries for the 64-unit network, so we take first-order steps. Two parameters here so the surface can be drawn. Show the three failure modes live: slow, oscillating, diverging. Then the two-minima surface: the start decides where you end, which is why initialization matters. How the gradient is computed through the hidden layer is the next slide.

=== SLIDE 7 ===
Backpropagation: the chain rule, organized 
 [FIGURE: live canvas]
 $\cx{x}$ [slider] 
 $\cw{w}$ [slider] 
 $\cw{b}$ [slider] 
 forward backward reset 
 $\dfrac{\partial L}{\partial \cw{w}} = \dfrac{\partial L}{\partial \ch{a}}\cdot\dfrac{\partial \ch{a}}{\partial z}\cdot\dfrac{\partial z}{\partial \cw{w}}$ 
 One neuron: $z = \cw{w}\cx{x} + \cw{b}$, $\ch{a} = \sigma(z)$, $L = -\log \ch{a}$ for label $y = 1$. 
 Forward: compute each node from the nodes before it. 
 Backward: multiply local derivatives from the loss back to each weight. 
 Every node stores one number forward and one number backward.
--- speaker notes ---
One neuron, one example with label y equal to one. Press forward: values fill left to right. Press backward: derivatives fill right to left, each edge multiplying by a local derivative, the derivative of a node with respect to its direct input. The gradient for w is the product along the path. In a network a weight in the first layer reaches the loss through every output, and the chain rule sums over those paths; backpropagation organizes this so each node's derivative is computed once and reused by everything upstream of it. That is why the backward pass costs about as much as the forward pass, however many weights there are. Frameworks such as PyTorch do the bookkeeping over graphs with millions of nodes.

=== SLIDE 8 ===
Train on MNIST, live 
 Stochastic gradient descent: each step uses one mini-batch, whose gradient is noisy but equals the full gradient on average. One epoch is one pass over the training images. The stopping epoch is chosen on the validation set; the test set is reported once. 
 [FIGURE: live canvas]
--- speaker notes ---
Stochastic gradient descent: the gradient is averaged over a mini-batch, not the whole data set, so a step costs 32 forward-backward passes instead of 4,000; the mini-batch gradient is unbiased for the full gradient, which is why the noisy steps still head downhill. Batch size one is the noisiest; the full batch is smooth but gives one step per epoch. Four thousand training images, a thousand validation images for choosing the epoch, a thousand test images reported once at the chosen epoch. Before each run, ask the class to predict: what happens with zero hidden units (that is multinomial logistic regression again), with a learning rate ten times larger, with batch size one? Then run. Watch training and validation accuracy separate when the training set is small.

=== SLIDE 10 ===
Overfitting 
 [FIGURE: live canvas]
 $L_\lambda(\btheta) = L(\btheta) + \frac{\lambda}{2}\,\|\cw{\bW}\|^2$ 
 Weight decay penalizes the weight matrices only; biases are not penalized, as in ridge regression. 
 500 images, 101,770 parameters: training accuracy reaches 100%, validation accuracy stalls. 
 Remedies: more data, weight decay $\lambda$, early stopping at the best validation epoch.
--- speaker notes ---
Same trainer, preset to a small sample and a large network: 128 hidden units give 101,770 parameters for 500 images. The dashed line marks the epoch with the best validation accuracy: early stopping. Raise lambda and the gap narrows. The validation set chooses the epoch; the test accuracy is then reported once at that epoch, so it stays an honest estimate. With this many parameters a held-out set is not optional.

=== SLIDE 11 ===
A statistician's view 
 Generalized linear model [FIGURE: live canvas]
 $g(\mu) = \cw{\bw}^{\!\top}\cx{\bx} + \cw{b}$ Features fixed by the analyst. 
 Basis expansion [FIGURE: live canvas]
 $g(\mu) = \sum_j \cw{w_j}\,B_j(\cx{\bx}) + \cw{b}$ Basis $B_j$ fixed in advance: splines, polynomials. 
 Neural network [FIGURE: live canvas]
 $g(\mu) = \sum_j \cw{w_j}\,\ch{h_j}(\cx{\bx};\cw{\bW_1}) + \cw{b}$ Basis learned from the data. 
 $g$ is the link; for a class probability, the logit. The activation $\varphi$ is its inverse. 
 Many parameters, no convexity, no closed-form standard errors. Regularize, hold out data, and report uncertainty by resampling.
--- speaker notes ---
For this audience the network is a GLM with a learned basis. Everything they know about likelihood, overfitting, and validation carries over. What does not carry over: closed-form inference, convexity, and standard errors for free.

=== SLIDE 12 ===
A neural network is a weighting estimator 
 [FIGURE: live canvas]
 features [menu] another test digit 
 $\hat y(\bx) = \sum_{i=1}^{n} w_i(\bx)\, Y_i$ 
 $w_i(\bx) = \ch{\bh}(\bx)^{\!\top}\,(\ch{H}^{\!\top}\ch{H} + \lambda I)^{-1}\,\ch{\bh}(\bx_i)$ 
 $\ch{H}$ stacks the features $\ch{\bh}(\bx_i)$ of the $n$ training images; $Y_i$ is the one-hot label of image $i$. 
 Freeze the learned features and replace the softmax layer by ridge regression on them. 
 The prediction is then a linear smoother, as with ridge regression and smoothing splines. 
 Unlike k-NN and kernel weights, these can be negative and need not sum to one.
--- speaker notes ---
The same formula as ridge regression, with h in place of x. Given the learned features the map from labels to prediction is linear, so every tool for linear smoothers applies: the hat matrix, degrees of freedom, leave-one-out. Two qualifications. The features were learned from the same labels, so the full map is not linear; the weighting view holds given the features, as k-NN weights hold given a metric that was itself chosen using the labels. And the real output layer is a softmax trained jointly by gradient descent; the ridge smoother shown here replaces it on the same frozen features, and its test accuracy is printed next to the network's. Switch to raw pixels: the same formula on the wrong features, and the training digits with the largest weights stop resembling the query.

=== SLIDE 13 ===
Summary and reading 
 [FIGURE: live canvas] 
 A neuron is a weighted sum and a nonlinear function. 
 A hidden layer learns features. The output layer is multinomial logistic regression on them. 
 Training minimizes the average negative log-likelihood by gradient descent. 
 Backpropagation computes every gradient with the chain rule, at the cost of one more pass. 
 Many parameters: choose epochs and $\lambda$ on a validation set, regularize, stop early. 
 Reading: Goodfellow, Bengio, Courville, Deep Learning (2016), ch. 6 and 8; Hastie, Tibshirani, Friedman, ESL , ch. 11; Nielsen, Neural Networks and Deep Learning (online).
