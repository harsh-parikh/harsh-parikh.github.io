=== SLIDE 2 ===
A task: read a handwritten digit 
 MNIST test images. Click one. 
 [FIGURE: live canvas] Hover over the large digit to read a pixel value. 
 Each image has 28 × 28 = 784 pixels. 
 Each pixel is a number between 0 (white) and 1 (black). 
 $\cx{\bx} \in [0,1]^{784}$ 
 $y \in \{0,1,\dots,9\}$ 
 60,000 training images and 10,000 test images (LeCun, Cortes, Burges). This deck carries 5,000 and 1,000 of them.
--- speaker notes ---
Start concrete. The input is a grid of grey levels; the output is one of ten labels. Everything that follows is about building a function from the 784 numbers to the label.

=== SLIDE 3 ===
Start from logistic regression 
 [FIGURE: live canvas]
 another digit Click a template to enlarge it. 
 $\cp{p_k} = \Pr(y = k \mid \cx{\bx}) = \dfrac{\exp(\cw{\bw_k}^{\!\top}\cx{\bx} + \cw{b_k})}{\sum_{j} \exp(\cw{\bw_j}^{\!\top}\cx{\bx} + \cw{b_j})}$ 
 Each class $k$ has its own weight vector $\cw{\bw_k}$ with 784 entries. 
 Drawn as an image: red pixels vote for $k$, blue pixels vote against. 
 Fit on 60,000 images: 90% test accuracy.
--- speaker notes ---
This is multinomial logistic regression, the model the class already knows. The weights are a template per class. The score for class k is the match between the image and template k. Softmax turns the ten scores into probabilities. Ten percent of test digits are wrong.

 $\ch{\bh} = g(\cw{\bW_1}\cx{\bx} + \cw{\bb_1})$

--- speaker notes ---
This is the whole idea of the lecture. Two inputs instead of 784 so the boundary can be drawn. First set one hidden unit: it is logistic regression, one straight line, and on XOR it stalls near fifty percent. Then raise the hidden units. The hidden units are learned features, each a half-plane. The output is logistic regression on those features. Increase the hidden units for the spiral; switch to linear to see the collapse from the previous slide.

 Pretrained network, 64 ReLU units, 97% test accuracy.

--- speaker notes ---
The 8 by 8 grid is the hidden vector h; dark cells are active units. The bars are p. Draw a 7 with a crossbar, or a thin 1, and watch the probabilities move. A badly centred digit fails: the network has no translation invariance.

=== SLIDE 6 ===
Learning: gradient descent on the negative log-likelihood 
 [FIGURE: live canvas]
 surface [menu] 
 $\eta$ [slider] 
 step run reset 
 Click the plot to choose a start. 
 $L(\btheta) = -\frac{1}{n}\sum_{i=1}^{n} \log \cp{p_{y_i}}$ 
 The loss is the negative log-likelihood, as in logistic regression. $\btheta$ holds every weight. 
 $\btheta \;\leftarrow\; \btheta - \eta\,\cl{\nabla_{\btheta} L(\btheta)}$ 
 Step downhill by $\eta$ times the gradient. Too small is slow; too large jumps across the valley.
--- speaker notes ---
The loss is minus the log of the probability the network assigns the true class, averaged over the data: the same objective as logistic regression, with the hidden layer's weights added to theta. Two parameters so the surface can be drawn; the real surface has 50,890 dimensions. Show the three failure modes live: slow, oscillating, diverging. Then the two-minima surface: neural network losses are not convex, and initialisation matters.

=== SLIDE 7 ===
Backpropagation: the chain rule, organized 
 [FIGURE: live canvas]
 $\cx{x}$ [slider] 
 $\cw{w}$ [slider] 
 $\cw{b}$ [slider] 
 forward backward reset 
 $\dfrac{\partial L}{\partial \cw{w}} = \dfrac{\partial L}{\partial \ch{a}}\cdot\dfrac{\partial \ch{a}}{\partial z}\cdot\dfrac{\partial z}{\partial \cw{w}}$ 
 Forward: compute each node from the nodes before it. 
 Backward: multiply local derivatives from the loss back to each weight. 
 Every node stores one number forward and one number backward.
--- speaker notes ---
One neuron, one example with label y equal to one. Press forward: values fill left to right. Press backward: derivatives fill right to left, each edge multiplying by a local derivative. The gradient for w is the product along the path. For a big network the same rule runs over a graph with millions of nodes; frameworks do the bookkeeping.

=== SLIDE 8 ===
Train on MNIST, live 
 One epoch is one pass over the training images, taken in mini-batches of the chosen size. Each mini-batch gives a noisy, cheap gradient. 
 [FIGURE: live canvas]
--- speaker notes ---
Stochastic gradient descent: the gradient is averaged over a mini-batch, not the whole data set, so a step costs 32 forward-backward passes instead of 5,000. Batch size one is the noisiest; the full batch is smooth but one step per epoch. Five thousand training images, one thousand test images, in the browser. Before each run, ask the class to predict: what happens with zero hidden units, with a learning rate ten times larger, with batch size one? Then run. Watch train and test accuracy diverge when the training set is small.

=== SLIDE 10 ===
Overfitting 
 [FIGURE: live canvas]
 $L_\lambda(\btheta) = L(\btheta) + \frac{\lambda}{2}\,\|\btheta\|^2$ 
 500 images, 128 hidden units: training accuracy reaches 100%, test accuracy stalls. 
 Remedies: more data, weight decay $\lambda$, early stopping at the best test epoch.
--- speaker notes ---
Same trainer, preset to a small sample and a large network. The dashed line marks the epoch with the best test accuracy: early stopping. Raise lambda and the gap narrows. A held-out set is not optional with this many parameters.

=== SLIDE 11 ===
A statistician's view 
 Generalized linear model [FIGURE: live canvas]
 $g^{-1}(\mu) = \cw{\bw}^{\!\top}\cx{\bx}$ Features fixed by the analyst. 
 Basis expansion [FIGURE: live canvas]
 $g^{-1}(\mu) = \sum_j \cw{w_j}\,\phi_j(\cx{\bx})$ Basis $\phi_j$ fixed in advance: splines, polynomials. 
 Neural network [FIGURE: live canvas]
 $g^{-1}(\mu) = \sum_j \cw{w_j}\,\ch{h_j}(\cx{\bx};\cw{\bW_1})$ Basis learned from the data. 
 Many parameters and few guarantees: regularize, hold out data, and report uncertainty.
--- speaker notes ---
For this audience the network is a GLM with a learned basis. Everything they know about likelihood, overfitting, and validation carries over. What does not carry over: closed-form inference, convexity, and standard errors for free.

=== SLIDE 12 ===
A neural network is a weighting estimator 
 [FIGURE: live canvas]
 features [menu] another test digit 
 $\hat y(\bx) = \sum_{i=1}^{n} w_i(\bx)\, Y_i$ 
 $w_i(\bx) = \ch{\bh}(\bx)^{\!\top}\,(\ch{H}^{\!\top}\ch{H} + \lambda I)^{-1}\,\ch{\bh}(\bx_i)$ 
 $\ch{H}$ stacks the features $\ch{\bh}(\bx_i)$ of the $n$ training images. 
 Freeze the learned features. The output layer is least squares on them. 
 So the prediction is a weighted sum of training labels, like k-NN, kernel, and spline smoothers. 
 The hidden layer learns which training points count as neighbours.
--- speaker notes ---
The same formula as linear regression, with h in place of x. Given the learned features the map from labels to prediction is linear, so every tool for linear smoothers applies: the hat matrix, degrees of freedom, leave-one-out. Two qualifications. The features were learned from the same labels, so the full map is not linear, the same status as a random forest given its leaves. And the real output layer is logistic regression on h, fit by iteratively reweighted least squares; the ridge-on-features smoother shown here is its least-squares version, and its test accuracy is printed. Switch to raw pixels: same formula, wrong metric, and the borrowed digits stop looking like the query.

=== SLIDE 13 ===
Summary and reading 
 [FIGURE: live canvas] 
 A neuron is a weighted sum and a nonlinear function. 
 A hidden layer learns features. The output layer is logistic regression on them. 
 Training minimizes the negative log-likelihood by gradient descent. 
 Backpropagation computes every gradient with the chain rule, at the cost of one more pass. 
 Many parameters: validate on held-out data, regularize, stop early. 
 Reading: Goodfellow, Bengio, Courville, Deep Learning (2016), ch. 6 and 8; Hastie, Tibshirani, Friedman, ESL , ch. 11; Nielsen, Neural Networks and Deep Learning (online). 
 Data: MNIST (LeCun, Cortes, Burges). Maths: KaTeX. Every figure is plain JavaScript in this folder; index_full.html has ten more slides.
