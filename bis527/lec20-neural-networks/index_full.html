A task: read a handwritten digit

MNIST test images. Click one.
Hover over the large digit to read a pixel value.

Each image: 28 × 28 = 784 numbers.

Each pixel between 0 (paper) and 1 (ink).

$\cx{\bx} \in [0,1]^{784}, \qquad y \in \{0,1,\dots,9\}$

4,000 training, 1,000 validation, 1,000 test images in this deck.

Start concrete. The input is a grid of grey levels; the output is one of ten labels. Everything that follows is about building a function from the 784 numbers to the label. MNIST has 60,000 training and 10,000 test images (LeCun, Cortes, Burges); this deck carries 4,000 for training, 1,000 as a validation set for choosing epochs, and 1,000 test images reported once.

An image is a vector

Read the pixels row by row.

$\cx{\bx} = (\cx{x_1}, \cx{x_2}, \dots, \cx{x_{784}})$

The model receives a list of 784 numbers, not a picture.

We want a function $f(\cx{\bx})$ that returns the digit.

The flattening throws away the neighbourhood structure. The fully connected network we build today does not know that pixel 29 sits under pixel 1. Convolutions, at the end, put that knowledge back.

Start from logistic regression

Click a template to enlarge it.
$\cp{p_k} = \Pr(y = k \mid \cx{\bx}) = \dfrac{\exp(\cw{\bw_k}^{\!\top}\cx{\bx} + \cw{b_k})}{\sum_{j} \exp(\cw{\bw_j}^{\!\top}\cx{\bx} + \cw{b_j})}$

One template $\cw{\bw_k}$ and intercept $\cw{b_k}$ per class.

The softmax turns ten scores into probabilities.

Red pixels raise the score for $k$, blue lower it.

90% test accuracy. Every boundary is a straight line.

This is multinomial logistic regression, the model the class already knows. The weights are a template per class. The score for class k is the match between the image and template k. Softmax turns the ten scores into probabilities. Ten percent of test digits are wrong, and no choice of the ten templates fixes that: the score for each class is linear in the pixels, so each boundary is flat. The weights were fit on all 60,000 training images. The score for class k is w_k transpose x plus b_k; the softmax exponentiates and normalizes the ten scores. Every boundary between two classes is a straight line, and the remaining ten percent of errors need boundaries that bend.

What one line cannot do

Logistic regression draws one straight boundary.

$\cw{\bw}^{\!\top}\cx{\bx} + \cw{b} = 0$

For the XOR, ring, and spiral data no line separates the classes.

The fix is new features. A neural network learns them.

Two inputs instead of 784, so we can draw the boundary. The logistic fit runs live. On the blobs it works; on the rest it stalls near fifty percent. Classically one would hand-build features such as x1 times x2 or the radius. The network builds them from data.

One neuron

$\ch{a} = \varphi\big(\cw{w_1}\cx{x_1} + \cw{w_2}\cx{x_2} + \cw{b}\big)$

A neuron is a weighted sum followed by a nonlinear function $\varphi$.

The weights set the direction of the boundary. The bias shifts it.

With a sigmoid $\varphi$, one neuron is logistic regression.

Drag the weights: the boundary rotates. Drag the bias: it translates. The shading is the activation a over the plane. Nothing here is new; a neuron is one logistic regression unit.

Activation functions

Solid: $\varphi(z)$. Dashed: the derivative $\varphi'(z)$, used in learning.

Without a nonlinear $\varphi$, stacked layers collapse to one linear map.

$\cw{\bW_2}(\cw{\bW_1}\cx{\bx}) = (\cw{\bW_2}\cw{\bW_1})\,\cx{\bx}$
Sigmoid and tanh saturate: the derivative vanishes far from zero, so learning slows. ReLU keeps a derivative of one on the positive side and is the default for hidden layers. The composition identity is why the nonlinearity is not optional.

A hidden layer

Two inputs here instead of 784, so the boundary can be drawn.

$\ch{\bh} = \varphi(\cw{\bW_1}\cx{\bx} + \cw{\bb_1})$
$\cp{\bp} = \mathrm{softmax}(\cw{\bW_2}\ch{\bh} + \cw{\bb_2})$

Each hidden unit: a weighted sum, then $\varphi(z) = \max(0, z)$.

Its sum is zero along one line (small panels).

Softmax on $\ch{\bh}$: straight in $\ch{\bh}$, bent in $\cx{\bx}$.

This is the whole idea of the lecture. Two inputs instead of 784 so the boundary can be drawn; the data are the XOR pattern (classes by quadrant), rings, or a spiral. First set one hidden unit: one straight line, and on XOR accuracy stalls near fifty percent. Then raise the hidden units: each learned feature is a ramp that is zero on one side of its line, and multinomial logistic regression on those features gives a boundary that is straight in h and therefore bends in x (piecewise linear for ReLU). Switch to the linear activation (phi is called the activation function): two linear maps compose to one linear map, so the model is again logistic regression on the raw inputs and the boundary stays straight. The learning rate eta is the step size of training, defined two slides on. With a linear activation, W2 times W1 x equals (W2 W1) x: two linear maps compose to one, and the boundary is straight again. Phi is called the activation function.

The same network on MNIST

$\cx{\bx}\in\R^{784} \;\to\; \ch{\bh}\in\R^{m} \;\to\; \cp{\bp}\in\R^{10}$
$\cw{\bW_1}\in\R^{m\times 784},\quad \cw{\bW_2}\in\R^{10\times m}$

Two inputs become 784. Two classes become ten.

With $m = 64$ hidden units: 50,890 parameters, against 7,850 for logistic regression.

Rectangles are drawn to scale. Zero hidden units is logistic regression. The parameter count grows linearly in m; the data stays at 60,000 images. Keep that ratio in mind for the overfitting slide.

The forward pass on a digit you draw

Draw in the left box with the mouse.
$\cx{\bx} \;\xrightarrow{\;\cw{\bW_1},\;\varphi\;}\; \ch{\bh} \;\xrightarrow{\;\cw{\bW_2},\;\mathrm{softmax}\;}\; \cp{\bp}$

Pretrained: 64 ReLU units, 97% test accuracy.

Draw a digit: 784 inputs, 64 features, 10 probabilities.

The 8 by 8 grid is the hidden vector h; dark cells are active units, those whose ReLU output is positive. The bars are p. Draw a 7 with a crossbar, or a thin 1, and watch the probabilities move. A badly centred digit fails: the network has no translation invariance. The forward pass computes p from x layer by layer. The network was trained beforehand on the 60,000 training images with 64 units and 20 epochs fixed in advance, so nothing about it was chosen on the test set.

The loss: cross-entropy

$L_i(\btheta) = -\log \cp{p_{y_i}}, \qquad L(\btheta) = \frac{1}{n}\sum_{i=1}^{n} L_i(\btheta)$

$\cp{p_{y_i}}$ is the probability the network gives the true class.

This is the negative log-likelihood of the multinomial model.

A confident wrong answer costs far more than a hesitant one.

Same loss as logistic regression; the parameters theta now include the hidden layer. Drag p toward zero and the loss explodes, which is why the gradient on a confident mistake is large.

Learning: gradient descent

Click the plot to choose a start.
$L(\btheta) = -\frac{1}{n}\sum_{i=1}^{n} \log \cp{p_{y_i}}(\cx{\bx_i};\btheta)$

The average negative log-likelihood, as in logistic regression.

$\btheta \;\leftarrow\; \btheta - \eta\,\cl{\nabla_{\btheta} L(\btheta)}$

Not convex, 50,890 parameters: take gradient steps.

Too small an $\eta$ is slow; too large jumps across the valley.

Two parameters so the surface can be drawn; the real surface has 50,890 dimensions. Show the three failure modes live: slow, oscillating, diverging. Then the two-minima surface: neural network losses are not convex, and initialisation matters. Theta holds every weight and intercept (called a bias in this literature). Logistic regression is convex and IRLS solves it in a few steps; here the loss is not convex and theta has 50,890 entries for the 64-unit network, so a Newton step would mean a 50,890 by 50,890 Hessian and we take first-order steps instead.

Backpropagation: the chain rule, organized

$\dfrac{\partial L}{\partial \cw{w}} = \dfrac{\partial L}{\partial \ch{a}}\cdot\dfrac{\partial \ch{a}}{\partial z}\cdot\dfrac{\partial z}{\partial \cw{w}}$

$z = \cw{w}\cx{x} + \cw{b}$,   $\ch{a} = \sigma(z) = \frac{1}{1+e^{-z}}$,   $L = -\log \ch{a}$ for $y = 1$.

Forward: each node from the nodes before it.

Backward: multiply local derivatives back to each weight.

One neuron, one example with label y equal to one. Press forward: values fill left to right. Press backward: derivatives fill right to left, each edge multiplying by a local derivative, the derivative of a node with respect to its direct input. The gradient for w is the product along the path. In a network a weight in the first layer reaches the loss through every output, and the chain rule sums over those paths; backpropagation organizes this so each node's derivative is computed once and reused by everything upstream of it. That is why the backward pass costs about as much as the forward pass, however many weights there are. Frameworks such as PyTorch do the bookkeeping over graphs with millions of nodes. Every node stores one number forward (its value) and one number backward (the derivative of the loss with respect to it). Sigma is the logistic function, the two-class softmax.

Backpropagation through the whole network

Pretrained network on a test digit.
$\cl{\bdelta_2} = \cp{\bp} - \mathbf{e}_{y}, \qquad \nabla_{\cw{\bW_2}} L = \cl{\bdelta_2}\,\ch{\bh}^{\!\top}$
$\cl{\bdelta_1} = (\cw{\bW_2}^{\!\top}\cl{\bdelta_2}) \odot \varphi'(\bz_1)$
$\nabla_{\cw{\bW_1}} L = \cl{\bdelta_1}\,\cx{\bx}^{\!\top}$

The output error is probability minus truth.

Each weight gradient is an outer product: error signal times the layer's input.

The top row is the forward pass; the bottom row is the backward pass in red. Delta two is the ten bars: the true class goes negative, the rest positive. Delta one is the 64 cells; ReLU zeroes the inactive units. The backward pass costs about as much as the forward pass.

Stochastic gradient descent

$\btheta \;\leftarrow\; \btheta - \eta\,\frac{1}{|B|}\sum_{i\in B} \cl{\nabla L_i(\btheta)}$

A mini-batch gradient is a noisy, cheap estimate of the full gradient.

One pass over all the data is an epoch.

Smaller batches: more steps per epoch, noisier path.

A real problem: logistic regression with one feature, so the two parameters w and b give a drawable loss surface over 200 points. Contours are the full-data loss. With batch size one the path jitters; with the full batch it is smooth but each step costs 200 gradients. Modern training uses batches of 32 to 512.

Five thousand training images, one thousand test images, in the browser. Before each run, ask the class to predict: what happens with zero hidden units, with a learning rate ten times larger, with batch size one? Then run. Watch train and test accuracy diverge when the training set is small.

What the hidden units learned

Click a tile.

Each tile: one row of $\cw{\bW_1}$ as a 28 × 28 image.

A hidden unit is a learned stroke template.

Right: the validation digits that activate it, and its ten output weights.

Compare with the ten logistic-regression templates: those were whole digits; these are parts. The output layer composes parts into digits with signed weights. This is the learned basis expansion. In 784 dimensions each unit's line from the playground is a hyperplane; drawn as an image it is a stroke template. Red is evidence for a digit, blue against.

Overfitting

$L_\lambda(\btheta) = L(\btheta) + \frac{\lambda}{2}\big(\|\cw{\bW_1}\|^2 + \|\cw{\bW_2}\|^2\big)$

500 images, 101,770 parameters: training hits 100%, validation stalls.

Remedies: more data, weight decay $\lambda$, early stopping on validation.

Same trainer, preset to a small sample and a large network: 128 hidden units give 101,770 parameters for 500 images. The dashed line marks the epoch with the best validation accuracy: early stopping. Raise lambda and the gap narrows. The validation set chooses the epoch; the test accuracy is then reported once at that epoch, so it stays an honest estimate. With this many parameters a held-out set is not optional. Weight decay shrinks the weights by a factor one minus eta lambda at each step; the intercepts are not penalized, as in ridge regression. The parameter count is 784 times 128 plus 128 plus 1,280 plus 10.

Toward images: convolution

$(\cw{K} * \cx{\bx})_{ij} = \sum_{u,v} \cw{K_{uv}}\;\cx{x_{i+u,\,j+v}}$

A convolution slides one small template over every position.

Nine weights instead of 784 per unit, and the same feature detector everywhere.

Convolutional networks learn the filters. Next lecture.

Edit the nine numbers in the grid. The fully connected network had to learn a stroke separately at every location; a convolution learns it once. That weight sharing is what makes image networks work.

A statistician's view

Generalized linear model

$g(\mu) = \cw{\bw}^{\!\top}\cx{\bx} + \cw{b}$

Features fixed by the analyst.

Basis expansion

$g(\mu) = \sum_j \cw{w_j}\,B_j(\cx{\bx}) + \cw{b}$

Basis $B_j$ fixed: splines, polynomials.

Neural network

$g(\mu) = \sum_j \cw{w_j}\,\ch{h_j}(\cx{\bx};\cw{\bW_1}) + \cw{b}$

Basis learned from the data.

$\mu = E[y \mid \cx{\bx}]$; $g$ is the link (the multinomial logit, inverse softmax); $\varphi$ is the hidden activation.

Many parameters, no convexity, no closed-form standard errors: regularize, hold out, resample.

For this audience the network is a GLM with a learned basis. Everything they know about likelihood, overfitting, and validation carries over. What does not carry over: closed-form inference, convexity, and standard errors for free.

With its features fixed, a network is a weighting estimator

$\hat y(\bx) = \sum_{i=1}^{n} w_i(\bx)\, Y_i$
$w_i(\bx) = \ch{\bh}(\bx)^{\!\top}\,(\ch{H}^{\!\top}\ch{H} + \lambda I)^{-1}\,\ch{\bh}(\bx_i)$

$\ch{H}$ stacks $\ch{\bh}(\bx_i)$ over $n = 4{,}000$ training images; $Y_i$ is the one-hot label.

Freeze the features; ridge-regress the labels on them.

$w_i(\bx)$ ignores the labels: a linear smoother, like ridge and splines.

Weights can be negative and need not sum to one.

The same formula as ridge regression, with h in place of x. Given the learned features the map from labels to prediction is linear, so every tool for linear smoothers applies: the hat matrix, degrees of freedom, leave-one-out. Two qualifications. The features were learned from the same labels, so the full map is not linear; the weighting view holds once the features are fixed, which is also the status of a random forest's weights given its trees. And the real output layer is a softmax trained jointly by gradient descent; the ridge smoother shown here replaces it on the same frozen features, and its test accuracy is printed next to the network's. Switch to raw pixels: the same formula with the pixels themselves as features, and the training digits with the largest weights stop resembling the test digit. The intercept is unpenalized, as on the previous slide. H stacks the 64 features of the 4,000 training images; Y_i is the ten-vector with a one at y_i, so the prediction is the largest entry of y-hat. Lambda is fixed at 0.001, not tuned; the intercept is unpenalized.

Summary

A neuron: a weighted sum, then a nonlinearity.

A hidden layer learns features; softmax regression on them.

Training: gradient descent on the average negative log-likelihood.

Backpropagation: the chain rule, one backward pass.

Many parameters: validation set, weight decay, early stopping.
